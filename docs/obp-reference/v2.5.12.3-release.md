## 📝 Descripción y Notas de Lanzamiento

Esta actualización establece las **pautas de marca oficiales** e integraciones de interfaz para el ecosistema corporativo de Fondo Thoth:

1.  **Estandarización de Logos y Estética**: Actualización de la paleta de colores corporativos e iconografía premium para alinearse con los componentes de diseño de la organización.
2.  **Parámetros de Payload de Negocios**: Define los formatos para inyectar diagnósticos y KPIs del simulador social en el pipeline de planes de negocio del API de Open Business Plan (OPB).
3.  **Seguridad Local-First**: Asegura la firma de las sesiones mediante hashes SHA-256 inmutables generados de manera local, protegiendo los datos confidenciales sobre tendencias electorales y delincuencia en la base de datos de Hermosillo.
